# 正则表达式





正则表达式有三种（regular expression）



## 普通正则





**常见元字符**

|               元字符               | 说明                                                         |
| :--------------------------------: | :----------------------------------------------------------- |
|                 ^                  | 以某个字符开头                                               |
|                 $                  | 以某个字符结尾                                               |
|                 .                  | 匹配任意单字符                                               |
|                 *                  | 对前一项进行0次或者多次重复匹配（0到无穷）                   |
|   {m,n}（需要转义变成`\{m,n\}`）   | 将前一项字符重复m-n次（至少m次，至多n次），{m,},{,n},{m, n}，前面不写就是0，后面不写就是无穷 |
|                 []                 | 对方括号内的单字符进行匹配                                   |
|                [^]                 | 不匹配方括号内的单字符                                       |
|                ^[]                 | 匹配以某个字符开头的行                                       |
|                 ()                 | 定义一个子表达式                                             |
| 词首【<或\b】和词尾锚定【>或者\b】 | 其后面的任意字符必须作为单词首部出现；其前面的任意字符必须作为单词尾部出现 |
|                 \                  | 转义字符，让一些特殊符号失效                                 |







举例：

```
grep "^$" /etc/passwd ————————————————————————————————查看空白的行

grep "^r" /etc/passwd ————————————————————————————————查看开头为r的行

grep "n$" /etc/passwd ————————————————————————————————查看结尾为n的行

grep "redhet." /etc/passwd ————————————————————————————————查看redhet加任意字符的行

grep "o\{1,2\}" /etc/passwd ————————————————————————————————这里加了\进行转义，找出任何包含 1 个或 2 个连续字母 "o" 的行

grep "[0-9]\{4\}" /etc/passwd ——————————————————————————————找出四位数的行
[0-9]：匹配任意一个数字（0 到 9）。
\{4\}：代表前面的内容（也就是数字）必须连续重复出现 4 次。

grep "[^0-9]" /etc/passwd ——————————————————————————————————找出非数字的行

grep "^[rot]" /etc/passwd ————————————————————————————————————找出r或o或t开头的行

grep "\bcat\b" test.txt —————————————————————————————————————只匹配出 cat

grep "\<cat" test.txt ———————————————————————————————————————匹配出 cat 和 catfish

grep "cat\>" test.txt ———————————————————————————————————————匹配出 cat、bobcat、copycat
```







**小练习：**

```
检索以r开头t结尾中间有任意2个字符的行信息
grep "^r..t$" test.txt

检索至少包含1个w字母的行信息
grep "w\{1,\}" test.txt

检索至少包含2个字母o的行信息
grep "o\{2,\}" test.txt

检索包含(.)的行信息
grep "\." test.txt

检索/etc/grub2.cfg文件中，以至少一个空白字符开头，后面跟上非空白字符的行
grep -E "[[:space:]]+[^[:space:]]+" /etc/grub2.cfg
```









## 扩展正则





除了支持普通正则，扩展正则还支持：



| 元字符 | 说明                                                         |
| :----: | :----------------------------------------------------------- |
|   ?    | 将前一项字符进行0次或者1次的重复匹配（？是0到1）（更接近于有或者没有） |
|   +    | 将前一项进行1次或者多次的重复匹配（*是0到无穷，+是1到无穷）  |
|   \|   | 匹配\|符号左边或者右边的字符（单纯的就是“或”的意思）         |







```
grep -E "https?://.*" 1.txt ————————————————————————————会匹配到http开头或https开头的
s?表示前面的s可以是0次也可以是1次，.*表示匹配任意个字符

egrep 等于 grep -E
```





了解一下：



**POSIX字符类**

• POSIX字符类是一个形如 `[ : : ]` 的特殊元序列（meta sequence），他可以用于匹配特定的字符范围

| 正则表达式 | 描述                                          | 示例            |
| :--------: | :-------------------------------------------- | :-------------- |
| [:alnum:]  | 匹配任意一个字母或数字字符                    | [[:alnum:]]+    |
| [:alpha:]  | 匹配任意一个字母字符（包括大小写字母）        | [[:alpha:]]     |
| [:blank:]  | 空格与制表符（横向和纵向）                    | [[:blank:]]*    |
| [:digit:]  | 匹配任意一个数字字符                          | [[:digit:]]?    |
| [:lower:]  | 匹配小写字母                                  | [[:lower:]]     |
| [:upper:]  | 匹配大写字母                                  | ([[:upper:]]+)? |
| [:punct:]  | 匹配标点符号                                  | [[:punct:]]     |
| [:space:]  | 匹配一个包括换行符、回车等在内的所有空白符    | [[:space:]]+    |
| [:graph:]  | 匹配任何一个可以看得见的且可以打印的字符      | [[:graph:]]     |
| [:xdigit:] | 任何一个十六进制数（即：0-9，a-f，A-F）       | [[:xdigit:]]+   |
| [:cntrl:]  | 任何一个控制字符（ASCII字符集中的前32个字符） | [[:cntrl:]]     |
| [:print:]  | 任何一个可以打印的字符                        | [[:print:]]     |
